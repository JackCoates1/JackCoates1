### AI and security projects

[The Gauntlet](https://github.com/JackCoates1/the-gauntlet) tests WebMCP-enabled AI agents against 16 tool attacks and scores each run. I built it for OpenAI's WebMCP Challenge. [Try it here](https://gauntlet.jackcoates.co.uk).

[Gauntlet: Ecology](https://github.com/JackCoates1/gauntlet-ecology) is the follow-up. Attacker and defender strategies compete in scored matches.

[DDOS-Notifications](https://github.com/JackCoates1/DDOS-Notifications) sends Discord alerts when network traffic exceeds a threshold.

[AI-DDOS-Firewall](https://github.com/JackCoates1/AI-DDOS-Firewall) is an educational prototype for DDoS detection and firewall responses on Linux. The machine-learning component is a placeholder.
